# balls.py

Physics ball room made with Python (pygame).

# Requirments:
+ pygame (https://pypi.org/project/pygame/)
+ pymunk (https://pypi.org/project/pymunk/)
```
pip install pygame pymunk
```

## Supported systems:
Linux
Windows
MacOS
